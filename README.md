# MentorBridge

MentorBridge is a student mentorship platform that helps juniors connect with seniors for mentorship, doubt solving, resource sharing, and placement guidance.

## Features
- User Login & Registration
- Mentor Directory
- Q&A Forum
- Messaging
- Resources
- Internship & Placement Hub

## Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB Atlas
- Render
